🎯 ToolsWidget Component

Interactive demo of the DolphinCare ToolsWidget component

Component Overview

A collapsible toolbar widget with configurable tools, supporting both vertical and horizontal layouts. Tools can display icons with optional notification badges.

Component Props
Prop Type Default Description
isOpen boolean true Whether widget starts expanded
orientation 'vertical' | 'horizontal' 'vertical' Layout direction
size 'big' 'big' Widget size (currently only 'big')
tools Tool[] [] Array of tool objects with icon, label, badge, onClick
className string undefined Custom CSS classes
Usage Example
import { ToolsWidget } from './components/ToolsWidget/ToolsWidget'

export function App() {
  const tools = [
    { icon: 'ai', label: 'AI Tool', badge: 7 },
    { icon: 'comment', label: 'Comments', badge: 2 },
    { icon: 'info-small', label: 'Info' },
    { icon: 'checkmark', label: 'Verify', badge: 1 },
  ]

  return (
    <ToolsWidget
      isOpen={true}
      orientation="vertical"
      tools={tools}
    />
  )
}
